# AEROHEAL Cockpit

An interactive, first-person aircraft cockpit with an animated airport, flight instruments, wing inspection, and a microcapsule-based self-healing simulation.

Website: https://shmaa-h.github.io/aeroheal-cockpit/

## Explore the simulation

1. Select **Start Self-Inspection**, then **View Report**.
2. The first inspection reports **Safe to fly**. Select **Start Flight** for a 20-second flight.
3. The next inspection reveals wing damage and blocks flight.
4. Select **Self-Healing** to watch capsules release repair agent and seal the crack.
5. Once the wing is safe, another flight becomes available.

The website is a standalone `index.html` with embedded styles and scripts. GitHub Pages publishes the repository root from the `main` branch.
